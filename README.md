# YTDownloader Skript

## Einrichtung
* **Setzen der Pfade:** Variablen `VENV_PYTHON` und `SCRIPT_PATH` müssen so gesetzt werdne, dass sie als Absoluter Pfad auf das heruntergeladene Repository verweißen
* **Verknüpfung erstellen:** Um das Skript von einem beliebigen Ordner aus zu starten, kann man eine Verknüpfung erstellen. Damit die relativen Pfade zur verknüpfung stimmen, muss man erst den Ausführungsordner löschen: **Rechtsklick -> Eigenschaften -> Verknüpfung -> Ausführen in:** Pfad einfach löschen

FFMPEG muss installiert sein:
* Windows: Lade es auf [ffmpeg.org](ffmpeg.org) herunter und füge den bin-Ordner zu deinem System-Pfad (PATH) hinzu.
* Mac: `brew install ffmpeg`
* Linux: `sudo apt install ffmpeg`

## Ausführen
* Doppelklick auf Verknüpfung
* Einfügen eines Video- oder Playlistlinks
* Eingeben in welchem Ordner (Startend von der Stelle der Verknüpfung) die Downloads gespeichert werden sollen
* geduldig warten bis alles heruntergeladen ist





# YTDownloader Script (English)

## Setup
* **Setting the paths:** The variables `VENV_PYTHON` and `SCRIPT_PATH` must be set so that they refer to the downloaded repository as an absolute path.
* **Create shortcut:** To start the script from any folder, you can create a shortcut. To ensure that the relative paths to the shortcut are correct, you must first delete the execution folder: **Right-click -> Properties -> Shortcut -> Run in:** Simply delete the path

FFMPEG must be installed:
* Windows: Download it from [ffmpeg.org](ffmpeg.org) and add the bin folder to your system path (PATH).
* Mac: `brew install ffmpeg`
* Linux: `sudo apt install ffmpeg`

## Execute
* Double-click on the shortcut
* Insert a video or playlist link
* Enter the folder (starting from the location of the shortcut) where the downloads should be saved
* Wait patiently until everything has been downloaded
